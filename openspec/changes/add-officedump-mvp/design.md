# Design: add-officedump-mvp

## Context

新規 Rust プロジェクト。動機とスコープは proposal.md を参照。技術的前提として、xlsx を含む OOXML 形式は「zip コンテナ + XML パーツ」であり、既存の高レベルライブラリ（calamine 等）はセル値の抽象化を目的とするため、書式・結合セル・メディアのアンカー等の構造属性が削られる。本プロジェクトの原則「属性を全保持する」と矛盾するため、生 XML を自前で剥がす方針を取る。

## Goals / Non-Goals

**Goals:**

- xlsx →「正規化 JSON IR + `media/` 子フォルダ」の分解パイプラインを確立する
- `inspect` / `read` による段階的開示（エージェントがトークンを節約しながら読める CLI 形状）
- 巨大シートでもストリーミング処理でメモリ使用量を抑える
- 将来の docx / pptx 対応が「形式プロファイルの追加」で済む共通骨格にする

**Non-Goals:**

- Markdown 等への変換・整形（LLM の責務）
- 数式の評価、日付等の意味変換
- docx / pptx 対応、MCP サーバー化（後続 change）

## Decisions

### D1: 高レベルクレートを使わず `zip` + `quick-xml` で自前分解する

- **理由**: 全保持の原則を満たすには生 XML へのアクセスが必須。`quick-xml` はストリーミングパースが可能で巨大シートにも対応できる
- **代替案**: `calamine`（却下 — 構造属性が失われる）、`ooxmlsdk`（却下 — MVP には過剰。型安全性は魅力だがスキーマ生成コードが巨大で、必要部分の手書きの方が小さい）

### D2: IR の正規化レベルは「構造は正規化、属性は全保持」

- OOXML を 1:1 で JSON 化すると名前空間ノイズでトークンが爆発する。行・セル等の構造単位には正規化した形を与える
- ただし属性（型、書式識別子、数式文字列、結合範囲、座標）は欠落なく保持し、意味変換（日付の ISO 化等）は一切行わない
- **代替案**: 生 XML をそのまま出力（却下 — トークン効率が壊滅的で LLM が溺れる）

### D3: CLI 形状は `inspect` / `read` の2サブコマンド

- `officedump inspect <file>`: シート名・寸法の概要のみ返す
- `officedump read <file> [--sheet <name>] [--range A1:F50]`: JSON IR を標準出力へ
- メディア抽出先は `--out <dir>` で指定し、`<dir>/media/` に展開。JSON からは相対パスで参照
- **代替案**: 1コマンドで全出力（却下 — 巨大ファイルでエージェントのコンテキストが死ぬ）

### D4: エラーは機械可読に統一する

- 非ゼロ終了コード + 標準エラーへ JSON（種別・メッセージ）。エージェントが自力でリトライ・代替処理を判断できるようにする

### D5: 共通パイプライン + 形式プロファイルの分離

- `zip展開 → XML parse → IR 構築 → JSON 出力` の骨格は形式共通とし、SpreadsheetML 固有の解釈（共有文字列の解決、スタイル表の参照等）をプロファイルとして隔離。docx / pptx 追加時の差分を最小化する

## Risks / Trade-offs

- [OOXML 仕様の広さにより、共有文字列・スタイル・テーマ等の解決に漏れが出る] → MVP では「値・型・書式識別子・数式・結合セル」に絞り、未知の要素は生 XML を素通しで保持する escape hatch を IR に用意する（落とさないことが最優先）
- [`quick-xml` は名前空間解決が手動で煩雑] → 対象は SpreadsheetML の少数名前空間に限定されるため許容。共通化するユーティリティを1箇所に集める
- [シート寸法は `dimension` 属性が不正確な実ファイルが存在する] → inspect は `dimension` 属性を優先し、欠落・不正時のみ走査で確定する

## Open Questions

- ~~`media/` の出力先の既定値~~ → **解決済み**: `--out` 省略時は `<ファイル名>.officedump/` に出力する（2026-08-10 ユーザー決定）
- `read` のトークン上限オプション（`--max-tokens` 的な打ち止め＋続きカーソル）の要否。MVP では範囲指定のみで様子見
